r2d2box

The panel on the right is one R2D2Box.mount call into an empty <div>. The header above it — the topic field, the session picker, the two buttons — is this page's own, built on the router's REST endpoints, because the box draws the conversation and the host draws everything around it.

Open this page in a second tab on the same session to watch both halves of one conversation: a turn started in either tab appears in both, and blocks the other tab's input while it runs.

Context is the box's ride-along JSON. Type something into the context field and the demo's build_prompt hook prepends it to whatever you ask next — which is how a host sends the text a reader has selected in a document.
